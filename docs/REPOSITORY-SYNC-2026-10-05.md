# Сохранение исправлений Avito в GitHub, 05.10.2026

Сохранены проверка наличия по связанному поставщику, долговременное удержание
неподтверждённых товаров, восстановление вернувшихся остатков, исправление
устаревших категорий и обязательных полей, а также соблюдение остановки
публикации владельцем. Добавлены служба/таймер аудита остатков и проверки.

Исходники сверены с /opt/avito-bridge/src. Рабочая ветка —
codex/runtime-safety-review. В main эти изменения автоматически не сливаются.
Серверные службы, объявления и управление публикацией не менялись во время
сохранения. Временные outputs, browser state, резервные копии модулей и
приватные runtime-файлы не включены в новые коммиты.
