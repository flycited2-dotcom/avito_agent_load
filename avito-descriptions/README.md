# Готовые описания Avito

`manifest.json` сопоставляет стабильный ключ группы с отдельным UTF-8
`.txt`-файлом. Цены в тексты не включаются: Bridge рассчитывает их при каждой
сборке фида.

Редактировать библиотеку рекомендуется через Avito Studio. Studio хранит
локальную принадлежность и ожидающие изменения по профилям, а при публикации
отправляет только patch выбранного профиля. Сервер повторно проверяет
принадлежность ключей и не позволяет одному профилю изменить или удалить
описание другого.

Правила:

- имя файла — один безопасный компонент с расширением `.txt`;
- один файл — не больше 128 КиБ и не пустой после удаления пробелов;
- путь не может выходить из этого каталога;
- один файл не назначается двум разным ключам;
- `manifest.json`, файлы, серверная ownership-карта, профильный конфиг и XML
  продвигаются одной журналируемой транзакцией.

Не копируйте сюда XLS/XLSX поставщиков, отчёты Avito, секреты или runtime-файлы.
Для ручной серверной публикации используйте `avito_bridge.profile_publish`;
прямое копирование manifest и текстов может нарушить профильную транзакцию.
